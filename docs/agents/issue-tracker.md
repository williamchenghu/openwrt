# Issue tracker

This repository uses GitHub Issues for work tracking.

## Workflow

- Read and write issues with the `gh` CLI.
- Use the repository configured by the `origin` remote (`williamchenghu/openwrt`).
- Pull requests are not treated as an issue-tracker request surface by default.

## Useful commands

```bash
gh issue list
gh issue view <number>
gh issue create
gh issue comment <number>
```
